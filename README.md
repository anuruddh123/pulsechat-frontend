# 💬 PulseChat

PulseChat is a **real-time chat application** built with the MERN stack. It supports secure authentication, real-time messaging, online user status, and profile management.

## ✨ Features

* 🔐 JWT Authentication
* 💬 Real-time messaging with Socket.IO
* 🟢 Online/Offline user status
* 👤 Profile management
* 🖼️ Cloudinary profile image upload
* 📱 Responsive UI
* 🔒 Protected API routes

## 🛠️ Tech Stack

**Frontend:** React.js, Vite, Tailwind CSS, Axios, Socket.IO

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, Socket.IO

**Services:** Cloudinary, Render, Netlify

## ⚙️ Setup

```bash
git clone https://github.com/anuruddh123/pulsechat-frontend.git

cd client
npm install
npm run dev
```

Create `.env`:

```env
VITE_API_URL=http://localhost:5001
```
